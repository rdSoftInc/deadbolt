# Changelog

Notable changes to Deadbolt are documented here.

## 1.2.0 — 2026-08-25

- Added guided assessment, engagement, scope, report, health, and tool-management workflows.
- Added saved engagement targets, enforceable traffic ceilings, scan profiles, and authorization snapshots.
- Added resumable web assessments with cached evidence, durable timing, and scanner lifecycle reporting.
- Added browser-assisted API discovery and value-free API evidence with provenance, methods, schemas, scope classification, and reconciliation conflicts.
- Added technical and stakeholder reports with detailed evidence and prioritized manual-testing handoff.
- Added managed Docker tool status, diagnostics, candidate testing, promotion, rollback, upgrades, and safe cleanup.
- Expanded web coverage with Arjun, Naabu, TLSx, browser traffic, and safer Nuclei execution.
- Added an engagement-gated network assessment foundation and network reports.
- Hardened repository privacy defaults for reports, engagements, targets, captures, credentials, and client data.
